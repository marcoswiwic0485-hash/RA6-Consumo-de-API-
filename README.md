# 🏆 Consumo de API: Rick and Morty

## 🚀 Contexto

Este proyecto demuestra cómo consumir una API pública y mostrar datos dinámicamente usando tecnologías web básicas. Es una forma práctica de aprender cómo funcionan las aplicaciones modernas.

---

## 💻 Tecnologías Utilizadas

* **HTML** → estructura de la página
* **CSS** → diseño y estilos de la pagina
* **JavaScript** → Funcionalidad de la pagina
* **API pública** → datos obtenidos desde Rick and Morty

---

## 🌐 API utilizada

👉 https://rickandmortyapi.com/api/character

Esta API proporciona información sobre los personajes de la serie, como:

* Nombre
* Imagen
* Estado
* Especie
* Género

---

## 🔄 Flujo del programa

1. Se carga la página
2. JavaScript hace una petición a la API
3. La API responde con datos de personajes
4. Se recorren los datos
5. Se crean tarjetas automáticamente
6. Se muestran en pantalla

---

## 🎯 Resultado

La aplicación muestra:

✔ Lista de personajes
✔ Imagen de cada personaje
✔ Información básica
✔ Diseño moderno con tarjetas
